# oct-retinal-classification
ML pipeline classifying retinal OCT scans into 4 diagnostic categories (Normal, CNV, DME, Drusen) using MedMNIST v2. Benchmarks CNN, MLP, RNN, SVC bagging, and soft-voting ensembles with Sobel edge detection, PCA, and min-max scaling preprocessing. Evaluated on accuracy, precision, recall, and ROC-AUC for clinical viability.
